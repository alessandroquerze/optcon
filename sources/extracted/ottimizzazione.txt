Consider the unconstrained optimization problem

Convexity and gradient monotonicity
If ℓis differentiable and convex, then for all zA, zB ∈Z it holds
ℓ(zB) ≥ℓ(zA) + ∇ℓ(zA)⊤(zB −zA)
If ℓis differentiable and convex, then its gradient ∇ℓ: Rd →Rd satisfies
⊤ ∇ℓ(zA) −∇ℓ(zB) (zA −zB) ≥0

Strict convexity and gradient monotonicity
A function ℓis strictly convex if for zA̸ = zB and θ ∈(0, 1)
ℓ(θzA + (1 −θ)zB) < θℓ(zA) + (1 −θ)ℓ(zB)

⊤ ∇ℓ(zA) −∇ℓ(zB) (zA −zB) > 0
for all zA, zB ∈Z.
That is, the gradient ∇ℓis a strictly monotone operator

Minimization of convex functions
Proposition (Prop. B.10 Nonlin. Progr.)
Let Z ⊂Rd be a convex set and ℓ: Z →R a convex function. Then a local minimum of ℓis also a
global minimum.
Proof
Let z⋆be a local minimum of ℓ. Suppose by contradiction that z⋆is not a global minimum. Then there
exists a global minimum ¯z ∈X such that ℓ(¯z) < ℓ(z⋆).
Using the definition of convexity it holds
ℓ(θz⋆+ (1 −θ)¯z) ≤θℓ(z⋆) + (1 −θ)ℓ(¯z)
< θℓ(z⋆) + (1 −θ)ℓ(z⋆) = ℓ(z⋆),
for every θ ∈[0, 1).
This contradicts the assumption that z⋆is a local minimum since we found points, ˜z = θz⋆+ (1 −θ)¯z
with θ ∈[0, 1), arbitrarily close to z⋆with ℓ(˜z) < ℓ(z⋆). This concludes the proof.

Necessary and sufficient condition of optimality (unconstrained)
For the unconstrained minimization of a convex function it can be shown that the first order necessary
condition of optimality is also sufficient (for a global minimum).
Proposition (Prop. 1.1.2 Nonlin. Progr.)
Let ℓ: Rd →R be a convex function. Then z⋆is a global minimum if and only if ∇ℓ(z⋆) = 0.
Proof (sketch)
Use the fact (Proposition B3 in Nonlinear Programming) that ℓconvex if and only if
ℓ(z) ≥ℓ(z⋆) + ∇ℓ(z⋆)T (z −z⋆)
for all z ∈Rd. Thus, if ∇ℓ(z⋆) = 0 it follows immediately ℓ(z) ≥ℓ(z⋆) for all z ∈Rd. The converse is
true by the first order necessary condition and the fact that a local minimum is a global minimum.

===== PDF PAGE 28 =====
Optimization algorithms: two-step procedure
We consider a general two-step procedure that reads as follows
zk+1 = zk + γkdk, k = 1, 2, . . .
in which
1. each γk > 0 is a “step-size”,
2. dk ∈Rd is a “direction”.
The goal is to
1. choose a direction dk along which the cost decreases for γk sufficiently small;
2. select a step-size γk guaranteeing a sufficient decrease.
Notation In other references these are called line-search methods.

===== PDF PAGE 29 =====
Gradient methods: introduction
Let zk be such that ∇ℓ(zk)̸ = 0. We start by considering the update rule
zk+1 = zk −γk∇ℓ(zk),
i.e., we choose dk = −∇ℓ(zk).
From the first order Taylor expansion of ℓat zk we have
ℓ(zk+1) = ℓ(zk) + ∇ℓ(zk)T (zk+1 −zk) + o(∥zk+1 −zk∥)
= ℓ(zk) −γk∥∇ℓ(zk)∥2 + o(γk).
Thus, for γk > 0 sufficiently small it can be shown that ℓ(zk+1) < ℓ(zk).

===== PDF PAGE 33 =====
Steepest descent (gradient method)
The update rule obtained for Dk = I,
zk+1 = zk −γk∇ℓ(zk),
is called steepest descent (or gradient method tout court).
The name steepest descent is due to the following property. The normalized negative gradient direction
dk = −∇ℓ(zk) ∥∇ℓ(zk)∥,
minimizes the slope ∇ℓ(zk)T dk among all normalized directions, i.e., it gives the steepest descent.

Newton’s method for root finding
Consider the nonlinear root (zero) finding problem

Idea: Iteratively refine the solution such that the improved guess zk+1 represents a root (zero) of the
linear approximation of r about the current tentative solution zk.
Consider the linear approximation of r about zk, we have
rk(zk + ∆zk) = r(zk) + ∇r(zk)⊤∆zk

∆zk = − ∇r(zk)⊤ −1r(zk)

zk+1 = zk − ∇r(zk)⊤ −1r(zk).

Gradient methods via quadratic optimization
Similarly to the Newton’s method, a descent direction ∆zk = Dk∇ℓ(zk) can be seen as the direction
that minimizes at each iteration a different quadratic approximation of ℓabout zk.
In fact, consider the quadratic approximation ℓk(z) of ℓabout zk given by

∆zk = −Dk∇ℓ(zk)
Remark Direction ∆zk can be computed by solving the quadratic approximation. This can be very
helpful in optimization problems in which a gradient is not (easily) available, but it is to solve a quadratic
optimization problem. It is useful also in case the domain is a compact convex set.
